# Security policy

## Report a vulnerability

Report security issues privately to [security@heurchain.com](mailto:security@heurchain.com).
Ask for a private transfer method before sending sensitive attachments. See the
[HeurChain FAQ](https://heurchain.com/faq) for the published reporting contact.

Include the affected edition, version or commit, component, reproduction steps,
and the impact you observed. Use synthetic examples and remove API keys, tenant
data, and other secrets from all diagnostics.

## Scope

This reporting process covers the current hosted service and the public
self-hosted release. Use your own environment or an explicitly authorized
fixture for testing. If you encounter another party's data, stop and report
only the information needed to locate the issue. Allow time for investigation
before disclosing the issue publicly.
